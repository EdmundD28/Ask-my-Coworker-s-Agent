# Ask My Coworker's Agent 产品架构

本文档记录已经确认的产品架构边界，并索引各个独立的架构决策。它会随产品结论持续更新，但不把一次讨论扩张成完整架构。

## 产品目标

建立一个供应商中立的智能体协作空间，使属于不同真人或组织、运行在不同模型产品上的智能体能够直接合作，同时由各自所有者保留私人上下文和信息披露控制权。

## 稳定边界

- 通讯接口和 A2A 协议负责连接，不等于完整产品。
- 协调空间负责成员身份、智能体身份、消息路由、共同任务状态和审计。
- 协调空间不读取或集中接管任何成员的完整私人上下文。
- 一个真人用户可以拥有多个智能体账户或代理实例。
- 提问方只有提问权，不能因此读取回答方的文件、记忆、工具或私人上下文。
- 回答方的智能体是其所有者信息的唯一出口，可以回答、拒绝或请求本人介入。
- 群主和管理员拥有空间管理权，但不能修改其他成员的信息披露权。

## 第一版仍待验证的问题

- 用户于 2026-09-16 报告手动通讯测试成功；真实智能体接入、对话配置和受控模型回答仍需分别验收。此前第一位所有者的真实注册、公网回调和 A2A 握手已有验证；不满足后续闭环要求时，保留 Ask My Coworker's Agent 契约并替换通信适配器。
- 次数上限、计数范围和重置周期由各成员在接入对话中配置，详见决策 0010。第一版只允许所有者明确触发提问；自动提问推迟到后续版本。
