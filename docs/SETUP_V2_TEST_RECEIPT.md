# Ask My Coworker's Agent 第二版接入测试记录

日期：2026-09-16。构建产物位于 `dist/Ask My Coworker's Agent v2/`，与上一版分开放置。

## 功能证据

- 93 项本地测试通过。
- 最终可执行文件另通过 9 项离线打包验收，覆盖内置手册、实际界面服务生成代码、单次领取、配置保存和第二空间名片复用；哈希及检查明细位于 `build/setup-package-verification.json`。
- 界面操作生成唯一配置码；本机码单次领取、15 分钟有效。受邀码包含唯一空间和一次性加入凭证。
- 再次加入复用名片和通用偏好，不继承旧空间披露授权；相同空间重复加入不分配第二个身份。
- 随机挑战必须先通过实际本机接口收取，再由当前工具会话回复。错误回复、重复回复和跨空间激活被拒绝。
- 两个独立本机 HTTP 节点完成真实收发接口上的提问、收取、回复和对端确认；外部注册服务及公网隧道为替身。
- 逐次确认必须经本人界面入口批准，智能体会话凭证不能自批；额度超限不会进入智能体队列，发送方得到拒绝状态。
- 验证旧会话凭证失效、伪造回复凭证被拒绝、答案不可改写及相同回复重试不重复投递。

## 中文与界面证据

使用本机已有 Edge 的隔离无界面浏览器实例检查最终打包程序的实际界面，未安装浏览器组件。

- 页面明确使用 UTF-8 和 `zh-CN`，实际渲染中文正常。
- 点击生成、复制、保存接入码，验证剪贴板文本保留中文，下载文件能严格按 UTF-8 解码。
- 1365 像素桌面和 390 像素窄屏均无横向溢出；没有浏览器脚本异常。
- 截图及机器回执：`build/hub-browser-evidence/`。

内置浏览器控制工具因本机运行环境缺少路径未能启动，验收改用已有 Edge；没有将工具不可用冒充为界面通过。

## 验证边界

挑战证明工具会话持有凭证并完成收发，不证明模型供应商签发的平台对话身份。当前只支持主动收取，不能唤醒关闭的模型对话。

资料检索及自然语言披露判断仍由用户自己的智能体执行，不能由本地测试推出模型不会泄密。真实异地两位所有者、真实公网服务及用户选择的模型对话测试尚未代做。

没有为用户安装程序、创建真实远端账户或开启真实公网隧道。测试数据仅放在临时目录及 `build/` 下；发布目录不包含本人的预填配置、会话凭证或测试记录。
