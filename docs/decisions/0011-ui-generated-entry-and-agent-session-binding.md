# 架构决策 0011：界面生成接入码、个人档案复用与智能体会话绑定

- 状态：已接受并实现本地验证版本；真实异地运行仍待用户测试
- 日期：2026-09-16
- 部分取代：决策 0010 的静态手册式配置码，以及“没有智能体收发通道、所有入站统一待人工”的实现边界

## 用户确认的要求

配置码和邀请码都由产品界面操作生成。接入码必须指定唯一目标，不能将同一份说明书误当成某个空间或对话的身份。已有配置的用户再加入新空间，不应重新填写整套名片与通用偏好。界面、复制内容、保存文件及程序输出使用 UTF-8，并验证中文显示。

## 用户流程

1. 双击 Ask My Coworker's Agent 打开本机界面；启动界面不创建公网隧道或远端身份。
2. 创建者点击“生成配置码”。代码绑定唯一的本机创建记录，有效期 15 分钟、一次领取；取得远端空间编号后绑定该空间。
3. 已接入的创建者点击“邀请成员”。邀请码含唯一远端空间编号、一次性加入凭证和最小操作引导，默认 24 小时有效；不携带群主密钥或群主电脑目录。
4. 受邀者直接把完整邀请码交给自己的智能体，不必先创建另一个空间。
5. 智能体调用内置手册和接入接口。首次询问名片与权限；再次接入复用本机名片及通用偏好，只核对新空间差异。
6. 同一空间重复加入返回已有记录，不创建第二个身份，不让新对话偷偷抢占原对话。本人需在界面明确选择“更换负责对话”才能更新会话凭证。

## 手册与代码的关系

手册是程序内置、可复用、带版本的操作说明。接入码是界面生成的一次性目标凭证，加上告诉智能体如何读取手册的最小引导。对用户仍是“一次复制粘贴”；不要求用户手工组合两份内容，也不把整本说明重复塞进每次邀请。

## 复用范围

本机只复用名片、逐次确认偏好和额度偏好，作为新空间的待确认建议。提问者、主题、项目和披露授权不跨空间继承。每个空间使用独立节点目录、会话凭证、问题队列、回答额度和策略；底层远端接入身份也独立，不声称本次已实现跨空间统一远端账户。

## 会话绑定与实际收发

- 接入码被领取后分配本机工具会话凭证，绑定本次节点、智能体编号和空间编号。
- 智能体必须通过真实本机接口主动收取一次随机挑战，并回复其编号和随机值；读手册或仅启动节点不能通过验证。
- 界面分别展示通讯已连接、等待会话挑战、会话通道已验证。
- 同一空间只有一个当前工具会话凭证；本人更换负责对话后旧凭证失效。
- 问题按空间成员、自述发送者、第一版明确触发、双边会话编号、时间、重放、待处理上限和本方策略检查。
- 预授权范围内的问题进入智能体队列；逐次确认及范围外的问题只能由本人通过界面批准本次处理。智能体收发凭证不能调用批准接口。
- 智能体主动收取问题并提交回答；回答通过原问题独有的回复凭证返回。接收端核对请求、双方身份和会话，拒绝伪造、串线及改写已收到回复。重试同一回答不重复计数。
- 为在模型执行前限制费用，进入处理队列即预留一次额度；包括最终未知或拒绝的处理。本手册必须明确解释这项保守计数语义。

## 验证边界

挑战验证的是持有本机凭证的工具会话收发能力，不是模型供应商签发的对话身份认证。对话名称是本人智能体的自述，不能称为已认证平台会话编号。

当前采用主动收取；程序不能唤醒关闭的模型对话，不自动创建轮询任务。用户的现有智能体负责按授权检索资料和判断自然语言披露边界；程序约束对象、次数、确认状态及返回路由，不宣称已经证明模型绝不泄密。

本次本地验收使用两个独立本机 HTTP 节点、真实会话挑战与异步回答往返，替换外部网络服务和隧道。浏览器验收单独覆盖界面生成、中文显示、剪贴板复制及窄屏布局。真实异地两位所有者与具体模型对话的使用效果仍待用户测试。

## 2026-09-16：补齐本人可主动打开的入口
