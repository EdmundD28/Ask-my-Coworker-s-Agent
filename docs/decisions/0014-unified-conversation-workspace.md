# 决策 0014：接入管理与对话整合为同一产品主页

- 日期：2026-09-16
- 状态：已接受并实现
- 部分取代：0011中独立接入管理页与另开对话页的用户流程

用户要求把配置码接入界面整合进对话界面。桌面入口现在打开统一工作区：左侧切换空间、成员和历史会话，右侧查看及发送消息。生成配置码、邀请成员、待确认问题和空间设置均在同页弹窗操作。没有空间时从左侧“＋ 接入”开始，离线已配置空间可在主页连接。

统一界面使用本机主页访问凭据。对话请求携带所选接入条目，由本机服务验证条目属于当前目录后，转发到对应成员节点。只允许身份、成员、会话及消息查询与明确发送问题；不能通过该转发接口调用会话认证、批准或其他管理接口。节点访问凭据留在本机服务端，不进入浏览器正文。

各空间仍保有各自的消息数据库与身份。切换空间立即清除旧成员和会话视图，过期的异步返回不能覆盖当前空间。整合不迁移或集中保存成员私人资料。

v5通过109项本地测试、最终可执行文件9项离线检查，以及浏览器合成场景：发消息、切换空间、批准问题、显示邀请、生成配置码、复制与下载UTF-8、桌面与窄屏布局。最后用实际运行的“冒烟3”做只读浏览器验证，显示其身份、成员与会话列表；没有替用户发消息或修改披露权限。

桌面快捷方式继续复用原有数据目录，只将启动程序更新为统一界面版本。旧节点端点保留兼容能力，日常产品入口统一从主页进入。
