# 架构决策 0003 异地协作空间与可转让群主

- 状态：已接受
- 日期：2026-09-15
- 范围：第一版远程访问、协作空间治理和群主管理权转让

## 背景

第一版最终验收必须发生在两个异地用户、两个真实账户和两个独立运行环境之间。同一台电脑或同一局域网内的演示不足以证明产品解决了跨所有者协作问题。

双边正文仍然遵循既有私聊边界，但双边会话存在于一个可管理的协调空间中。创建空间的用户需要拥有高于普通成员的空间管理权限，同时该管理责任不能永久绑定最初创建者。

## 决策

### 1. 第一版必须支持异地访问

- 协调空间和监视页必须能够通过公网供受邀用户访问。
- A、B 分别在自己的设备或独立运行环境中接入自己的智能体，不共享进程、账户、凭据或私人上下文目录。
- 双方使用各自浏览器访问同一协调空间，但只能看到各自权限允许的内容。
- 开发阶段可以使用本机或局域网环境，最终验收不能以这些结果代替异地证据。

### 2. 空间创建者成为初始群主

- 创建协调空间的用户自动成为初始群主。
- 群主拥有高于普通成员的空间管理权限，包括管理空间、邀请或移除成员，以及在后续存在管理员功能时设置管理员。
- 群主管理权不包含其他成员的私人上下文读取权、双边私聊正文读取权或披露范围修改权。

### 3. 群主权限可以主动转让

- 当前群主可以主动把群主身份转让给另一名用户。
- 第一版只允许转让给当前协调空间内的用户，避免把空间交给尚未完成接入的未知对象。
- 被指定的新群主必须主动接受；接受前，原群主继续承担群主职责并保留管理权。
- 新群主接受后，群主身份和管理权一次性完成转移，空间在任一时刻只有一名群主。
- 转让完成后，原群主默认成为普通成员；只有新群主再次明确授权，原群主才能成为管理员。
- 转让完成后，新群主获得空间管理权，但不会继承或扩大任何成员的信息披露权，也不会因此看到此前无权查看的双边正文。
- 群主转让必须形成审计记录，至少包含原群主、新群主和发生时间。

### 4. 后续议题

群主失联时的恢复、共同管理或紧急接管机制不进入第一版，记录在后续议题清单中。它不改变“群主管理权可转让、成员披露权不可随之转让”的稳定边界。

## 第一版验收

- 两名异地用户通过不同网络进入同一协调空间。
- 双方分别连接自己的真实智能体账户和运行环境。
- 双方能够通过各自浏览器访问监视页，并且看不到权限之外的双边正文。
- 空间创建者初始拥有群主管理权。
- 当前群主能够向空间内另一名用户发起群主转让，目标用户拒绝或尚未接受时不发生转移。
- 目标用户接受后，新群主能够执行群主管理操作，原群主降为普通成员且不能继续保留群主或管理员权限。
- 转让不会改变任何成员的披露规则或历史正文可见性。
- 群主转让事件出现在测试审计中。
