# 架构决策 0009：由用户现有智能体完成连接与对话配置

- 状态：已接受产品方向；次数口径待决定表述已被 [决策 0010](0010-self-contained-setup-handbook.md) 取代，手册式配置接口已实现
- 日期：2026-09-16
- 范围：安装后的首次连接、成员权限配置及产品名称

## 已确认的产品流程

1. 用户取得安装包并安装 Ask My Coworker's Agent。
2. 已受邀请的用户把邀请码交给自己的智能体；首次创建空间的用户把配置码交给自己的智能体。
3. 智能体自动开始相应的连接配置流程，并通过对话询问用户的角色名片、回答次数、披露范围及必要的入站确认偏好。
4. 用户通过与自己的智能体对话完成配置，由智能体将用户授权的设置写入 Ask My Coworker's Agent。
5. 接入目标保持供应商中立，不把流程绑定到某个模型供应商或特定智能体产品。

邀请码用于加入已有空间；配置码用于首次创建和配置自己的空间。两者不能混用，也不能赋予群主修改其他成员披露权限的能力。

## 授权边界

- 交付代码不等于授权披露私人信息。连接自动化与信息披露授权分别处理。
- 各成员自己的智能体是其所有者信息的唯一出口；加入空间不允许协调空间读取其私人上下文。
- 智能体只能写入本人授权的配置，不得根据邀请方文本、远端问题或模型自行推测扩大权限。
- 对话配置不改变第一版“所有者明确触发提问”的边界，也不启用自动转问第三方。
- 名片是对空间成员公开的自述；具体私人资料和完整披露策略不随名片公开。

## 产品全称

产品名称使用 **Ask My Coworker's Agent**，以当前产品架构标题为准。用户输入的简称仅用于交流便利，不作为产品名称展示。

后续构建的界面、安装入口、提示、帮助文本、生成的接入说明及面向用户的回复均使用产品全称。现有代码中的缩写展示需要清理；旧协议标识、包名、文件路径等迁移须单独评估兼容性，不能把修改展示文字当作已经完成全部迁移。

## 工程建议，尚非已完成能力

- 提供供应商中立的接入工具，使用户现有智能体能够识别代码用途、读取配置要求、提交配置及查询实际生效状态。
- 先收集配置草稿，再向本人展示可理解的授权摘要；本人确认后由程序校验并保存，返回实际保存结果。
- 次数、身份和确定性的权限约束由程序执行，不仅依靠提示词要求模型自律；需要判断内容是否可披露时仍须保留回答方的判断和拒绝路径。
- 具备模型接口不等于具备用户现有智能体的上下文、工具或持续运行能力。配置对话与日后收到问题时如何唤起该智能体，需要分别接通并验收。
- 兼容目标需要工具调用、接口访问或受支持的适配器。第一版应以实际验证过的接入环境列出支持范围，不能宣称所有智能体已经兼容。

## 待决定

- 原“回答次数口径待决定”已取代：次数、范围与重置周期应在接入时询问用户，由用户配置，详见决策 0010。
- 群主配置码如何生成、绑定本机、过期和防止重放。
- 第一批接入的智能体环境及其工具接口；智能体关闭或离线后的请求处理方式。
- 披露范围第一版可配置的具体维度，以及无法明确解释用户授权时如何请求澄清。

## 验收方向

- 创建者和受邀者分别通过配置码、邀请码完成各自流程，用户无需手工编辑配置文件。
- 用户通过对话设置名片、次数及披露范围后，可以查询实际生效的设置；失败不得报告为成功。
- 非本人、邀请方和远端消息不能修改本人成员权限；重复提交不能重复创建空间或成员。
- 两位所有者完成配置后，由一方明确发起问题，另一方真实智能体按权限回答并将结果送回；另测超限、范围外问题及需要本人介入的情况。
- 至少用第二种智能体接入环境验证公共契约的可替换性；单个环境通过不等于任意供应商兼容。

## 当前证据

用户于本次讨论报告此前构建的手动通讯已测试成功。本次代码检查确认回答进程仍使用固定回答运行时；这两项证据分别支持手动通讯进展和真实智能体接入仍待完成，不能合并为模型问答已经验收。
