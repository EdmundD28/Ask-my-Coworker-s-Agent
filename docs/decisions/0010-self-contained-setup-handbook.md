## 用户确认的修正

次数上限、计数范围、重置周期和披露范围是接入时由智能体询问本人、由本人回答的配置。不能因为这些值尚未填写，就停止构建等待产品设计者替每位用户作答。

配置码采用类似技能手册的自包含文本，包含配置要求、可调用接口、环境条件、操作顺序和成功判据。用户把它交给自己的智能体，智能体据此自行询问、组织配置、调用接口并核验接入，无需逐一适配模型供应商接口。

## 本次工程实现

- 提供独立 Windows 便携可执行程序，名称为 Ask My Coworker's Agent；不安装系统服务或修改开机启动。
- 提供可直接交给新对话的中文 Markdown 配置码；创建者还可生成内含一次性邀请的受邀者版本。
- 统一命令接口提供要求查询、配置校验、确认摘要绑定写入、连接启动、状态查询、成员查询、既有本地通讯接口调用及停止。
- 配置结构严格拒绝未知字段、通配授权、布尔类型次数及未替换占位内容。本人可以选择按问答链、提问者或总量计数，并选择不重置或滚动秒数窗口；不支持的要求必须明确报告，不暗中替换。
- 配置和连接回执区分保存成功、启动中和真实连接成功。只有服务端端点探测、握手和成员列表核验通过后才返回连接成功。
- 独立数据目录和进程锁保护既有实例；恢复使用已有凭据。创建操作响应不确定时保留现场，不盲目重复创建。
- 凭据和本地接口令牌绑定当前 Windows 用户加密保存。智能体通过命令调用接口，不需要读取密钥。确认摘要只绑定配置内容，不被宣称为真人身份认证。

## 明确的验收边界

本切片验证的是“智能体读手册、问用户、写入配置、接通既有通讯”。没有新增模型供应商调用，也没有宣称后台模型自动回答已经完成。

用户期望的完整策略被保存并可回读；本次新节点实际入站模式统一为要求本人介入，避免把尚未运行的自然语言披露判断、回答额度和模型执行机制当成已生效。状态回执同时说明期望策略与实际模式。

本地测试使用隔离临时目录、真实本机 HTTP 端口、Windows 加密存储及替身网络服务；不替用户安装、注册真实测试身份、创建真实空间或开启公网隧道。新对话与真实服务连接由用户自行测试。

## 后续验收

用户可用一个未见之前讨论的新对话，交付配置码，观察其能否独立完成问题收集、正确写入与连接核验。该结果需要保留命令回执，不能仅凭智能体自述判定成功。

后台智能体执行、逐次审批恢复和真实受控自动回答仍需要后续实现及跨所有者验收。
